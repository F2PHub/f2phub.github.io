О сайте

F2P Hub — каталог бесплатных игр. Здесь собраны только те проекты, в которые можно играть без оплаты: free-to-play, open-source и условно-бесплатные игры.

Сайт не требует регистрации, не хранит персональные данные и не содержит платных подписок. Каталог пополняется вручную.

Правила каталога

В каталог попадают игры, которые:

  • доступны бесплатно без ограничения по времени;
  • не требуют обязательной оплаты для игры;
  • не являются пиратскими копиями платных игр.
